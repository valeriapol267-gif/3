# Ассемблер и интерпретатор УВМ — вариант 22

Практическая работа № 3. Реализованы этапы 1–3.

Ассемблер переводит алгебраическую запись команд в промежуточное
представление, а затем в машинный код.

Интерпретатор выполняет загрузку константы, чтение и запись памяти.
Выбранный диапазон общей памяти сохраняется в XML.

Команда sqrt поддерживается ассемблером, но её выполнение относится
к этапу 4 и на данном этапе ещё не реализовано.

## Подготовка и проверки

Нужен Python 3.9 или новее.

После загрузки проекта в PyCharm команды выполняются в терминале
PowerShell из папки, содержащей src, tests и examples.

Для запуска используется команда py.
Приложения используют стандартную библиотеку Python.
Отдельная сборка Python-приложений не требуется.

```powershell
py -m pip install -r requirements.txt
New-Item -ItemType Directory -Force output | Out-Null
$env:PYTHONPATH = "src"
py -m unittest discover -s tests -v
py -m flake8 --max-line-length=79 --max-complexity=10 src tests
```

Ожидаются 36 тестов с результатом OK.
При успешной проверке flake8 не выводит замечаний.

Для тестов PYTHONPATH задаётся заново в каждом новом терминале.
Бинарные файлы и XML-дампы сохраняются в output/, исключённую из Git.

## Алгебраический язык

Одна команда записывается на одной строке.

M[x] обозначает значение ячейки x.
M[M[x]] обозначает косвенное обращение: адрес берётся из ячейки x.

Регистр букв M и sqrt не важен.
Разрешены пробелы и табуляция, пустые строки, комментарии после #.
Числа записываются в десятичном виде или с префиксом 0x.

Диапазон констант: 0..1073741823.
Диапазон адресов: 0..4194303.

Метки, переходы, переменные и произвольные выражения не поддерживаются.

| Форма команды | A | B | C |
|---|---|---|---|
| M[c] = b | 5 | Константа b | Адрес результата c |
| M[c] = M[M[b]] | 2 | Адрес указателя источника b | Адрес результата c |
| M[M[b]] = M[c] | 7 | Адрес указателя назначения b | Адрес источника c |
| M[M[c]] = sqrt(M[M[b]]) | 17 | Адрес указателя источника b | Адрес указателя назначения c |

У SQRT косвенно адресуются и источник, и назначение.
На этапе 3 эта команда кодируется, но не исполняется.

## Машинный формат

Байты записываются в порядке little-endian.
Заголовков и разделителей в бинарном файле нет.
Поле A занимает биты 0–4.
Резервные биты должны быть нулевыми.

| Команда | Размер | Поле B | Поле C |
|---|---|---|---|
| Загрузка константы | 8 байт | Биты 5–34 | Биты 35–56 |
| Чтение памяти | 7 байт | Биты 5–26 | Биты 27–48 |
| Запись памяти | 7 байт | Биты 5–26 | Биты 27–48 |
| sqrt | 7 байт | Биты 5–26 | Биты 27–48 |

## Параметры ассемблера

Запуск: `py src/main.py`.

Также доступен скрипт `.\run.bat`, передающий аргументы ассемблеру.

| Параметр | Назначение |
|---|---|
| -i, --input | Обязательный исходный файл UTF-8, допустим BOM. |
| -o, --output | Обязательный путь бинарного результата. |
| --stage | 1: промежуточные поля; 2: машинный код. По умолчанию 2. |
| --test | Вывод полей на этапе 1 или байтов на этапе 2. |
| -h, --help | Справка. |

На этапе 1 выходной бинарный файл не создаётся и не изменяется.
На этапе 2 выводится размер созданного файла в байтах.

## Параметры интерпретатора

Запуск: `py src/interpreter.py`.

| Параметр | Назначение |
|---|---|
| -i, --input | Обязательный бинарный файл программы. |
| -o, --output | Обязательный путь XML-дампа. |
| --start | Обязательный первый адрес дампа, 0..4194303. |
| --end | Обязательный последний адрес, от start до 4194303. |
| -h, --help | Справка. |

Обе границы диапазона включаются.

Относительные пути считаются от текущей рабочей папки.
Пути с пробелами заключаются в кавычки.
Выходная папка должна существовать.
Входной и выходной файлы должны различаться.

Успешный запуск заменяет прежний результат.
Ошибка программы до записи сохраняет прежний выходной файл.

Ошибки программы и файлов выводятся в stderr с кодом завершения 1.
Ошибки аргументов командной строки дают код 2.
Успешное выполнение даёт код 0.

## Модель общей памяти

Принята модель числовых ячеек с адресами 0..4194303.

Физическая разрядность данных в задании не задана:
ячейка хранит целое int или конечное вещественное float.
Один байт кода загружается в одну ячейку.

Код занимает адреса от 0 до размера бинарного файла минус 1.
Незаписанные ячейки содержат ноль.
Словарь хранит только заполненные ячейки.

Чтение данных, запись данных и выборка команд используют одну память.
Отдельного хранилища исполняемого кода и регистров нет.

Программа может прочитать или изменить код.
Будущая команда выбирается из уже изменённой памяти.
Если её ячейка содержит дробное число или целое вне 0..255,
выборка команды завершается ошибкой.

Дамп может включать код, если выбран соответствующий диапазон.

Косвенные указатели должны иметь тип int и попадать в диапазон адресов.
Значение float, даже 2.0, не используется как адрес.

## Цикл интерпретации

Интерпретатор последовательно:

1. Читает первый байт команды из общей памяти.
2. Определяет код операции и размер команды.
3. Читает остальные байты.
4. Декодирует поля и проверяет резервные биты.
5. Выполняет операцию.
6. Увеличивает счётчик на размер команды: 8 или 7 байт.

Исполнение заканчивается на границе загруженного бинарного файла.

Обрабатываются пустые программы, обрывы команд, неизвестные коды,
ненулевые резервные биты и недопустимые косвенные адреса.
Для ошибочной команды выводится её смещение в байтах.

Попытка исполнить sqrt на этапе 3 сообщает, что операция
пока не реализована.

## Проверка этапа 3: копирование массива

Программа examples/copy.asm создаёт массив [10, 20, 30]
по адресам 1000–1002 и копирует его по адресам 2000–2002.

Ячейка 500 содержит указатель источника.
Ячейка 501 содержит указатель назначения.
Ячейка 502 используется для промежуточного значения.

Код занимает адреса 0–113 и не пересекается с данными примера.

```powershell
py src/main.py -i examples/copy.asm -o output/copy.bin
py src/interpreter.py -i output/copy.bin -o output/copy.xml --start 2000 --end 2002
Get-Content output/copy.xml
```

Ожидаются размер программы 114 байт и 15 выполненных команд.

Ожидаемый дамп:

```xml
<?xml version='1.0' encoding='utf-8'?>
<memory start="2000" end="2002">
  <cell address="2000">10</cell>
  <cell address="2001">20</cell>
  <cell address="2002">30</cell>
</memory>
```

Исходный массив сохраняется, что проверяется автоматическим тестом.
Отдельные тесты читают код как данные и изменяют будущую команду,
проверяя использование общей памяти.

## Модули и функции

- src/spec.py: Field и Command описывают поля и команды;
  check_value проверяет тип и битовый диапазон значения.
- src/parser.py: memory строит шаблон обращения к памяти;
  parse_number читает число; parse_instruction распознаёт команду;
  parse_program разбирает исходник; format_fields форматирует поля.
- src/machine.py: encode_instruction упаковывает команду;
  encode_program возвращает список блоков;
  format_bytes форматирует байты.
- src/main.py: parse_args читает аргументы ассемблера;
  validate_paths проверяет пути; run выполняет этап;
  main обрабатывает ошибки и возвращает код завершения.
- src/decoder.py: command_for определяет команду по первому байту;
  decode_instruction восстанавливает поля и проверяет бинарный формат.
- src/memory.py: check_address и check_range проверяют адреса и диапазон;
  Memory.__init__ загружает код; read и write обращаются к общей памяти;
  read_bytes читает байты команды; dump возвращает выбранные ячейки.
- src/vm.py: VirtualMachine.__init__ создаёт состояние машины;
  load_constant, read_memory и write_memory исполняют операции памяти;
  fetch выбирает и декодирует текущую команду;
  run выполняет цикл интерпретации.
- src/interpreter.py: parse_args читает аргументы;
  save_dump создаёт XML; run выполняет программу и сохраняет дамп;
  main обрабатывает ошибки.
- tests/: проверки синтаксиса, байтов, CLI, декодирования и общей памяти.
  Вспомогательные assemble и execute собирают и запускают тестовый код.
- examples/: исходные демонстрационные программы.
- run.bat: запуск ассемблера через py с передачей аргументов.

## Оформление репозитория

Функции документированы с помощью docstring.
Изменения сохраняются отдельными Conventional/Scoped Commits.

В Git не добавляются архивы, бинарные результаты, output/,
кэш Python, виртуальные окружения, артефакты сборки
и настройки редактора.
